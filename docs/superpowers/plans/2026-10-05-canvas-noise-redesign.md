# Canvas noise redesign (S1 + S2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Canvas readback noise that no flat drawing, round trip or copy can detect (S1), with enough reach that the oracle's text and shape canvases differ per profile (S2), decided by a Phase 0 spike between a draw-time text offset (target) and readback-only noise (fallback).

**Architecture:** The pure noise rule moves to `PerturbRgbaEdges` in `additions/camoucfg/canvas_noise.cc`. It touches only interior pixels unlike all four neighbours, with premultiplied values clamped to `[0, alpha]`. `NoisedImage` in `canvas_readback.cc` applies the rule to a whole snapshot. In Blink, one method `CanvasRenderingContext::CamouNoised()` noises the snapshot for every consumer: `getImageData`, `toDataURL`, `toBlob`, `convertToBlob`, and `GetSourceImageForCanvas`, which serves `drawImage`, `createPattern`, `createImageBitmap`, `texImage2D` and captureStream's two-copy path. An imported-pixels flag on the 2D context keeps copies from carrying two fields. The target design adds a per-seed sub-pixel text origin in `DrawTextInternal` and an anti-aliased-geometry flag.

## Rulings made while planning

Each ruling is recorded here so the executor does not re-litigate it.

- **The spike builds on Windows only.** The spec says WSL incremental plus Windows. The spike needs the host GPU, and the Windows build is its compile check. A WSL build would leave `out/Default` holding throwaway code.
- **No quantisation of the text offset.** Skia's subpixel binning quantises a raw `[0, 1)` offset by itself. If the spike passes with raw values, raw values are the design.
- **C14 and the host runner's S2 text row ask for at least 6 of 8 distinct, not 8 of 8.** The spec's P1 accepts the text offset at 6 of 8. Under the target design, a text-only canvas gets no readback noise, so 8 of 8 would contradict P1. The shape canvas still needs 8 of 8.
- **P5 is a spike gate, not a final check under the fallback.** Readback noise gives the same text at x and x+1 different fields; that is the spec's recorded fallback gap. The final measurement records P5 and does not gate on it.
- **Density margin.** Pick the smallest candidate that passes S2 in both modes, then double it, because 8 seeds is a small sample.
- **C6 compares against the unconfigured live session.** Its drawing changes (a clear becomes a gradient triangle), so the persisted baseline's `readPixels` no longer applies. C11 keeps the rule-5 baseline check for WebGL instead: its unconfigured clear must equal the baseline `readPixels`.
- **Known gap added during planning:** a pattern created on one context and used to fill another does not flag the second. Record it in the measurement doc, not the spec.

```cpp
void PerturbRgbaEdges(uint8_t* data, const uint8_t* source, size_t width,
                      size_t height, size_t row_bytes, uint64_t seed,
                      double density, int32_t strength, uint8_t min_alpha) {
  // NaN-safe: !(density > 0) catches it.
  if (seed == 0 || data == nullptr || source == nullptr || !(density > 0.0) ||
      strength <= 0 || width < 3 || height < 3) {
    return;
  }
  density = std::min(density, 1.0);
  strength = std::min(strength, 255);
  min_alpha = std::max<uint8_t>(min_alpha, 1);
  static constexpr std::array<std::string_view, 3> kGate = {
      "canvas-gate-r", "canvas-gate-g", "canvas-gate-b"};
  static constexpr std::array<std::string_view, 3> kDelta = {
      "canvas-r", "canvas-g", "canvas-b"};
  const size_t size = (height - 1) * row_bytes + width * 4;
  // SAFETY: both buffers hold `height` rows of `row_bytes`, each at least
  // `width` * 4 bytes.
  const base::span<const uint8_t> src =
      UNSAFE_BUFFERS(base::span<const uint8_t>(source, size));
  const base::span<uint8_t> dst = UNSAFE_BUFFERS(base::span(data, size));
  auto at = [&](size_t x, size_t y) {
    return src.subspan(y * row_bytes + x * 4, 4u);
  };
  for (size_t y = 1; y + 1 < height; ++y) {
    for (size_t x = 1; x + 1 < width; ++x) {
      const base::span<const uint8_t> px = at(x, y);
      const uint8_t alpha = px[3];
      if (alpha < min_alpha || std::ranges::equal(px, at(x - 1, y)) ||
          std::ranges::equal(px, at(x + 1, y)) ||
          std::ranges::equal(px, at(x, y - 1)) ||
          std::ranges::equal(px, at(x, y + 1))) {
        continue;
      }
      // The position, not the index in the buffer: every reader of one
      // canvas state gets the same noise on the same pixel.
      const uint64_t index =
          (uint64_t{static_cast<uint32_t>(x)} << 32) | static_cast<uint32_t>(y);
      base::span<uint8_t> out = dst.subspan(y * row_bytes + x * 4, 4u);
      for (size_t ch = 0; ch < 3; ++ch) {
        if (DeriveUnit(seed, kGate[ch], index) >= density) {
          continue;
        }
        const int32_t v =
            int32_t{px[ch]} + DeriveDelta(seed, kDelta[ch], index, strength);
        out[ch] = static_cast<uint8_t>(std::clamp(v, 0, int32_t{alpha}));
      }
    }
  }
}
```

```cpp
void PerturbRgba(uint8_t* data, size_t width, size_t height, uint64_t seed,
                 double density, int32_t strength) {
  if (seed == 0 || data == nullptr || width == 0 || height == 0) {
    return;
  }
  // SAFETY: the caller's buffer holds width * height RGBA8 pixels.
  const base::span<const uint8_t> in = UNSAFE_BUFFERS(
      base::span<const uint8_t>(data, width * height * 4));
  const std::vector<uint8_t> source(in.begin(), in.end());
  // Fold content into the seed: same drawing reproduces, different drawings
  // diverge.
  PerturbRgbaEdges(data, source.data(), width, height, width * 4,
                   seed ^ ContentHash(source), density, strength,
                   /*min_alpha=*/255);
}
```
