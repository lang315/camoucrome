# S3b Device Ids That Round-Trip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every media device id the fork lists (real or phantom) works when a page passes it back to `setSinkId`, `AudioContext`, or `getUserMedia({deviceId: {exact}})`, as on stock Chrome.

**Architecture:**
- **Browser.** The browser folds `mediaDevices:seed` into Chrome's one device-id HMAC (`GetHMACForRawMediaDeviceID`), so every hash and every match agrees by construction. Output authorization and devicechange see the same phantoms as the enumerate reply, and a phantom speaker authorizes the default output.
- **Renderer.** The renderer stops rewriting ids and keeps only label masking, the pre-grant shape and the capability copy.
- **One rule.** A single camoucfg helper, `ActiveMediaDevicesSeed`, decides activation everywhere.

**Tech Stack:** Chromium 154 C++ (content/browser, Blink), `//components/camoucfg`, Python verify scripts (CDP via `lib_shell` on WSL, patchright on the Windows host).

**Spec:** `docs/superpowers/specs/2026-10-10-s3b-device-id-seed-design.md`

## Global Constraints

- **No JavaScript injection.** Every change is C++ in `additions/` or a patch.
- **One activation rule.** Media-device spoofing is active only when `mediaDevices:enabled` is true AND `mediaDevices:seed` is non-zero (`camoucfg::ActiveMediaDevicesSeed(scope) != 0`). This covers the browser phantoms, the HMAC fold, the renderer's pre-grant shape and label masking, and the track label. When inactive, every list equals stock (rule 5).
- **No new config keys.** The label defaults are `Integrated Camera`, `Microphone (Realtek Audio)` and `Speakers (Realtek Audio)`. They live once, as `camoucfg::kDefaultCameraLabel`, `kDefaultMicrophoneLabel` and `kDefaultSpeakerLabel` in `device_ids.h`.
- **The fold.** It goes inside `GetHMACForRawMediaDeviceID`, after the `""`/`default`/`communications` passthrough. It is one `hmac.Update(base::U32ToLittleEndian(seed))`, after the salt, in both the device and the group branch.
- **Phantoms are never written into `current_snapshot_`.** `CamouWithPhantoms` is applied in three places only: the enumerate reply, `NotifyDeviceChange`, and `AudioOutputAuthorizationHandler::TranslateDeviceID`.
- **A phantom speaker match authorizes `media::AudioDeviceDescription::kDefaultDeviceId`.** A phantom speaker exists only when the host's raw output list is empty.
- **RED first.** Every new row is seen failing before its pass counts, or it is labelled a guard. Every build reports **non-zero** steps, except the post-export no-op build, which must be `no work to do` or a few steps.
- **The test-only mutant (W13) is never committed or exported.** The box tree is clean, with the mutant reverted, before every W6.
- **Box source of truth.** `~/chromium/src`, branch `camoucrome/s3b`, cut at `camoucrome/main` = `4b5fdddcd8` (40 commits). `camoucrome/main` is not moved until landing (Task 5). `patches/` is regenerated by `scripts/export.sh`, never hand-edited.
- **Build lock and announcements.** Every box build, Windows build and host run holds the build lock (W1) and is announced to the owner in one line first. The controller tells session camoucrome-80 before the box branch moves and before any Windows build. Host runs are headless only.

```python
"""Applies EDITS from the module named by argv[1] to ~/chromium/src, all or nothing.

("replace", path, old, new, count): `old` must occur exactly `count` times.
Edits apply in order to the text as left by the edits before them.
"""
import pathlib
import runpy
import sys

SRC = pathlib.Path.home() / "chromium" / "src"
texts = {}
for _, path, old, new, count in runpy.run_path(sys.argv[1])["EDITS"]:
    t = texts[path] if path in texts else (SRC / path).read_text()
    if t.count(old) != count:
        sys.exit(f"{path}: {old[:70]!r} found {t.count(old)} times, expected {count}")
    texts[path] = t.replace(old, new)
for path, t in texts.items():
    (SRC / path).write_text(t)
print(f"applied to {len(texts)} files: {sorted(texts)}")
```

```python

    const ds = await navigator.mediaDevices.enumerateDevices();
    const out = ds.find(d => d.kind === 'audiooutput' && real(d));
    const mic = ds.find(d => d.kind === 'audioinput' && real(d));
    const r = {hasOut: !!out, hasMic: !!mic};

      const a = new Audio();
      try { await a.setSinkId(out.deviceId); r.sink = a.sinkId === out.deviceId ? 'ok' : 'mismatch'; }
      catch (e) { r.sink = e.name; }
      const ac = new AudioContext();
      // AudioContext fills its sink id set from its own enumerate after
      // construction; let that land before setSinkId.
      await navigator.mediaDevices.enumerateDevices();
      await new Promise(f => setTimeout(f, 500));
      try { await ac.setSinkId(out.deviceId); r.acSink = ac.sinkId === out.deviceId ? 'ok' : 'mismatch'; }
      catch (e) { r.acSink = e.name; }
      await ac.close();
```
