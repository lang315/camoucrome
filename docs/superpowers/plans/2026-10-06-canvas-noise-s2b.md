# Canvas noise S2b Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make canvas readback noise depend only on local content (each pixel's 3×3 source patch) and decide 2D eligibility per pixel through coverage masks, so the noise no longer moves with position, edits elsewhere, canvas reuse or WebGL sub-rect reads, and covers every anti-aliased operation without a list.

**Architecture:**
- `PerturbRgbaEdges` keys each pixel's noise by an FNV hash of its 3×3 source patch, hashed in top-down order, plus `canvas:seed`. Nothing else goes into the key: no position, no `CanvasStateHash`, no `ContentHash`.
- A new pure class, `camoucfg::CanvasNoiseMask` (`additions/camoucfg/canvas_mask.{h,cc}`), holds per-pixel `aa` / `imported` bits and the merge rules of the spec's table.
- In Blink, `Canvas2DRecorderContext::DrawInternal` replays each draw's `draw_func` into a side `MemoryManagedPaintCanvas`, plays the record onto an A8 bitmap and merges the coverage into the mask. `CamouNoised()` passes the mask, the mask generation and a per-context alpha floor to the noise pass.
- WebGL `readPixels` reads up to four 1px strips around the in-buffer part into a tight, bottom-up scratch copy before noising. The WebGL snapshot becomes opaque-only.

- gtest in `components_unittests`.
- Python 3: `verify_sp3a.py` on WSL `content_shell`, the patchright host runner `measure_canvas_noise.py` and `measure_step2.py` on Windows.

## Rulings made while planning

Each ruling is recorded here so the executor does not re-litigate it.

- **One byte per cell, two bits.** The spec says "two A8 masks". `CanvasNoiseMask` keeps one byte per cell with bit `kNoiseMaskAa` (1) and bit `kNoiseMaskImported` (2). It holds the same information in half the memory (16 MB at 4096²).
- **Image draws mark `imported` over their dirty rect, with no replay.** A texture-backed image cannot be played onto a CPU A8 bitmap, so a replay would mark nothing and leave imported pixels noised. The dirty rect contains the coverage, so this errs toward no noise. Rotated `drawImage` is covered by the same mark.
- **Composited draws mark `aa` over the clip bounds.** This covers filters, shadows that need compositing, full-canvas composite modes and `copy`. A filter's coverage is unbounded within the clip, so clip bounds is its coverage.
- **Draws inside a layer mark over their dirty rect.** The mark is `aa`, or `imported` for a pattern or image. `RestoreMatrixClipStack` stops at a layer, so a replay would place coverage wrongly.
- **`clearRect` goes through the replay with `Kind::kClear`.** It does not pass through `Draw`.
- **Text is skipped by `DrawType::kText`.**
- Superseded during implementation: layers and composited draws mark imported (spec amendments).
- **`CamouNoiseEligible()` means the mask holds a mark.** It is `camou_mask_ && !camou_mask_->empty()`. The spec's "some pixel is eligible" check would save only a noise pass that changes nothing, because every pixel is gated anyway.
- **`PerturbRgbaFromConfig` is the readPixels path only, so it is always bottom-up.**
- **Fixup targets (W6).**
  - A Blink file goes to the `sp3a-canvas-noise` commit.
  - An existing additions file goes to the last commit that touched it.
  - A new additions file (`canvas_mask.*`, `canvas_mask_unittest.cc`) goes to the same commit as `components/camoucfg/BUILD.gn`'s last-touch commit.
- **Cost is measured on WSL `content_shell`** (CPU raster, SwiftShader GL), seeded against unconfigured, and recorded with that caveat.

  ```python
  """Applies EDITS from the module named by argv[1] to ~/chromium/src, all or nothing.

  ("replace", path, old, new, count): `old` must occur exactly `count` times.
  ("cut", path, start, end): remove from `start` (which must occur exactly once) up

  """

  SRC = pathlib.Path.home() / "chromium" / "src"
  texts = {}
  for edit in runpy.run_path(sys.argv[1])["EDITS"]:
      kind, path = edit[0], edit[1]
      t = texts[path] if path in texts else (SRC / path).read_text()
      if kind == "replace":
          _, _, old, new, count = edit
          if t.count(old) != count:
              sys.exit(f"{path}: {old[:70]!r} found {t.count(old)} times, expected {count}")
          t = t.replace(old, new)
      else:
          _, _, start, end = edit
          if t.count(start) != 1:
              sys.exit(f"{path}: cut start {start[:70]!r} found {t.count(start)} times")
          i = t.index(start)
          j = t.find(end, i)
          if j < 0:
              sys.exit(f"{path}: cut end {end[:70]!r} not after start")
          t = t[:i] + t[j:]
      texts[path] = t
  for path, t in texts.items():
      (SRC / path).write_text(t)
  print(f"applied to {len(texts)} files: {sorted(texts)}")
  ```

  ```cpp
  #ifndef COMPONENTS_CAMOUCFG_CANVAS_MASK_H_
  #define COMPONENTS_CAMOUCFG_CANVAS_MASK_H_

  #include <cstddef>
  #include <cstdint>
  #include <vector>

  #include "components/camoucfg/canvas_noise.h"

  namespace camoucfg {

  // Which pixels of one 2D canvas may carry readback noise (canvas noise S2b,
  // spec section 2). A cell holds kNoiseMaskAa (its value depends on the
  // rasteriser) and/or kNoiseMaskImported (the page supplied it, or it may
  // already carry noise); a pixel is eligible iff its cell is exactly
  // kNoiseMaskAa. Blink merges every draw's coverage in. The cells are
  // allocated at the first mark, so a canvas that never marks costs one empty
  // object and reads as stock.
  class CanvasNoiseMask {
   public:
    // What one draw does to the pixels it covers (the spec's table).
    enum class Kind {
      kSolidOpaque,  // full coverage clears both marks; partial sets aa
      kSolid,        // full coverage leaves the marks; partial sets aa
      kClear,        // clearRect: as kSolidOpaque
      kAa,           // any coverage sets aa
      kImported,     // any coverage sets imported
    };
    // At most this many pixels get one cell each (4096 x 4096). A larger
    // canvas keeps 4 x 4 px cells: marked if any pixel would be, cleared only
    // when every pixel is fully covered.
    static constexpr size_t kMaxFullResPixels = size_t{4096} * 4096;

    CanvasNoiseMask(size_t width, size_t height);
    CanvasNoiseMask(const CanvasNoiseMask&) = delete;
    CanvasNoiseMask& operator=(const CanvasNoiseMask&) = delete;
    ~CanvasNoiseMask();

    // `coverage`: A8, `coverage_width` x `coverage_height`, rows
    // `coverage_stride` bytes apart, its (0, 0) at canvas pixel (left, top).
    // Parts outside the canvas are ignored.
    void Merge(const uint8_t* coverage, size_t coverage_stride, int64_t left,
               int64_t top, size_t coverage_width, size_t coverage_height,
               Kind kind);
    // Merge() with full coverage of a rect.
    void MarkRect(int64_t left, int64_t top, int64_t width, int64_t height,
                  Kind kind);

    bool empty() const { return cells_.empty(); }
    // The cells for PerturbRgbaEdges. Only meaningful when !empty(): an empty
    // view has cells == nullptr, which means "every pixel may change".
    NoiseMask view() const;
    // Bumps on every change, so a reader can key a cache on it.
    uint64_t generation() const { return generation_; }
    size_t width() const { return width_; }
    size_t height() const { return height_; }

   private:
    // `coverage` == nullptr means 255 everywhere.
    void Apply(const uint8_t* coverage, size_t coverage_stride, int64_t left,
               int64_t top, int64_t right, int64_t bottom, Kind kind);

    const size_t width_;
    const size_t height_;
    const int shift_;
    const size_t stride_;
    const size_t rows_;
    std::vector<uint8_t> cells_;
    uint64_t generation_ = 0;
  };

  }  // namespace camoucfg

  #endif  // COMPONENTS_CAMOUCFG_CANVAS_MASK_H_
  ```

  ```cpp
  void CanvasNoiseMask::Merge(const uint8_t* coverage, size_t coverage_stride,
                              int64_t left, int64_t top, size_t coverage_width,
                              size_t coverage_height, Kind kind) {
    if (coverage == nullptr || coverage_width == 0 || coverage_height == 0 ||
        coverage_stride < coverage_width) {
      return;
    }
    Apply(coverage, coverage_stride, left, top,
          left + static_cast<int64_t>(coverage_width),
          top + static_cast<int64_t>(coverage_height), kind);

                                 int64_t height, Kind kind) {
    if (width <= 0 || height <= 0) {
      return;
    }
    Apply(nullptr, 0, left, top, left + width, top + height, kind);
  }

    return {cells_.empty() ? nullptr : cells_.data(), stride_, shift_, width_,
            height_};

  void CanvasNoiseMask::Apply(const uint8_t* coverage, size_t coverage_stride,
                              int64_t left, int64_t top, int64_t right,
                              int64_t bottom, Kind kind) {
    const int64_t x0 = std::max<int64_t>(left, 0);
    const int64_t y0 = std::max<int64_t>(top, 0);
    const int64_t x1 = std::min<int64_t>(right, static_cast<int64_t>(width_));
    const int64_t y1 = std::min<int64_t>(bottom, static_cast<int64_t>(height_));
    if (x0 >= x1 || y0 >= y1) {

    // `coverage_stride` bytes, the last at least (right - left) long.
    const base::span<const uint8_t> cov =
        coverage == nullptr

                  coverage, static_cast<size_t>(bottom - top - 1) *
                                    coverage_stride +

    auto at = [&](int64_t x, int64_t y) -> uint8_t {
      return cov.empty() ? 255
                         : cov[static_cast<size_t>(y - top) * coverage_stride +
                               static_cast<size_t>(x - left)];
    };
    bool changed = false;
    if ((kind == Kind::kSolidOpaque || kind == Kind::kClear) && !cells_.empty()) {
      // Clear each cell whose every canvas pixel is fully covered.
      const int64_t s = int64_t{1} << shift_;
      for (int64_t cy = y0 >> shift_; cy <= (y1 - 1) >> shift_; ++cy) {
        for (int64_t cx = x0 >> shift_; cx <= (x1 - 1) >> shift_; ++cx) {
          uint8_t& cell = cells_[static_cast<size_t>(cy) * stride_ +
                                 static_cast<size_t>(cx)];
          if (cell == 0) {
            continue;
          }
          const int64_t px1 =
              std::min<int64_t>((cx + 1) * s, static_cast<int64_t>(width_));
          const int64_t py1 =
              std::min<int64_t>((cy + 1) * s, static_cast<int64_t>(height_));
          bool full = true;
          for (int64_t py = cy * s; py < py1 && full; ++py) {
            for (int64_t px = cx * s; px < px1 && full; ++px) {
              full = px >= x0 && px < x1 && py >= y0 && py < y1 &&
                     at(px, py) == 255;
            }
          }
          if (full) {
            cell = 0;
            changed = true;
          }
        }
      }
    }
    for (int64_t y = y0; y < y1; ++y) {
      for (int64_t x = x0; x < x1; ++x) {
        const uint8_t c = at(x, y);
        if (c == 0) {
          continue;
        }
        uint8_t bit = 0;
        switch (kind) {
          case Kind::kImported:
            bit = kNoiseMaskImported;
            break;
          case Kind::kAa:
            bit = kNoiseMaskAa;
            break;
          case Kind::kSolidOpaque:
          case Kind::kSolid:
          case Kind::kClear:
            bit = c == 255 ? 0 : kNoiseMaskAa;
            break;
        }
        if (bit == 0) {
          continue;
        }
        if (cells_.empty()) {
          cells_.assign(stride_ * rows_, 0);
        }
        uint8_t& cell = cells_[static_cast<size_t>(y >> shift_) * stride_ +
                               static_cast<size_t>(x >> shift_)];
        if ((cell & bit) != bit) {
          cell |= bit;
          changed = true;
        }
      }
    }
    if (changed) {
      ++generation_;
    }
  }

  }  // namespace camoucfg
  ```

  ```python
       "            for (const int64_t camou_cx :\n"
       "                 {camou_ex0 < camou_x0 ? camou_ex0 : int64_t{-1},\n"
  ```
