# SP4-battery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Config-drive the four `BatteryManager` getters at the Blink level so `navigator.getBattery()` reports the configured battery state, page-invisibly.

**Architecture:** SP0 per-getter override in `modules/battery/battery_manager.cc` — `charging`/`level`/`chargingTime`/`dischargingTime` return the config value when set, else the real `battery_status_` value. Ports Camoufox's battery getter overrides.

**Tech Stack:** Chromium/Blink C++ (`modules/battery`), `//components/camoucfg`, GN, Playwright verify over content_shell CDP.

## Global Constraints

- All spoofing at the C++/Blink level, NEVER injected JS. (project invariant)
- SP0 hook pattern: real value first, config override LAST, no-op when the key is absent (rule 5). Independent per getter.
- Config-key naming: colon namespace `battery:` (matching Camoufox). `battery:charging`, `battery:level`, `battery:chargingTime`, `battery:dischargingTime`.
- Keys triple-consistency: (1) `keys.h` constant, (2) `kAllKeys` array + `std::array<…, N>` size, (3) `declared` set in `keys_unittest.cc`. Count 70 → 74.
- Types: `battery:charging` → `GetBool` (`std::optional<bool>`); `battery:level`/`chargingTime`/`dischargingTime` → `GetDouble` (`std::optional<double>`). `ScopeFor(GetExecutionContext())` (BatteryManager is an ExecutionContext client) — if `GetExecutionContext()` is unavailable there, `ScopeFor(nullptr)` is equivalent (GlobalScope).
- Verify apparatus: `navigator.getBattery` is `[SecureContext]`-gated — drive over the `127.0.0.1` echo_server origin (mirror `verify_sp4_media`/`_geo`). Launch with `CAMOU_CONFIG`, NO CDP.
- Stock (secure) baseline: `charging:true, level:1, chargingTime:0, dischargingTime:Infinity`.
- Blink files live only in the checkout; edit via `pullfile`/`pushto`; extract to `patches/` in the final task. Confirm NON-ZERO build steps.

- [ ] **Step 1: verify script `scripts/verify_sp4_battery.py`** (secure origin via echo_server, NO CDP; `navigator.getBattery()`):
- **B1 (charging):** config `{"battery:charging":false}` → `charging===false` (stock is true).
- **B2 (level):** config `{"battery:level":0.42}` → `level===0.42` (stock 1).
- **B3 (chargingTime):** config `{"battery:chargingTime":1800}` → `chargingTime===1800` (stock 0).
- **B4 (dischargingTime):** config `{"battery:dischargingTime":9000}` → `dischargingTime===9000` (stock Infinity).
- **B5 (no-op absent):** config `{}` → `{charging:true, level:1, chargingTime:0, dischargingTime:Infinity}` (stock).

```python
import json, os, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import lib_shell, echo_server

PROBE = r"""(async () => {
  const b = await navigator.getBattery();
  return { charging:b.charging, level:b.level, chargingTime:b.chargingTime,
           dischargingTime: (b.dischargingTime===Infinity ? "Infinity" : b.dischargingTime) };
})()"""

def run(config):
    url,_,stop = echo_server.start([])
    try:
        v,e = lib_shell.session(config, [PROBE], navigate_to=url)
        if e: raise e
        return v[0]
    finally:
        stop()

def cfg(d): return json.dumps(d)

def main():
    r = {}
    r["B1"] = run(cfg({"battery:charging":False})).get("charging") is False
    r["B2"] = run(cfg({"battery:level":0.42})).get("level") == 0.42
    r["B3"] = run(cfg({"battery:chargingTime":1800})).get("chargingTime") == 1800
    r["B4"] = run(cfg({"battery:dischargingTime":9000})).get("dischargingTime") == 9000
    s = run(cfg({}))
    r["B5"] = (s.get("charging") is True and s.get("level") == 1
               and s.get("chargingTime") == 0 and s.get("dischargingTime") == "Infinity")
    EXPECTED=5
    for k in ("B1","B2","B3","B4","B5"): print(f"{k}: {'PASS' if r[k] else 'FAIL'}")
    n=sum(r.values()); print(f"{n}/{EXPECTED} " + ("ALL_PASS" if n==EXPECTED else "FAIL"))
    sys.exit(0 if n==EXPECTED else 1)

if __name__=="__main__": main()
```

bool BatteryManager::charging() {
  if (std::optional<bool> v = camoucfg::GetBool(
          camoucfg::ScopeFor(GetExecutionContext()),
          camoucfg::keys::kBatteryCharging)) {
    return *v;
  }
  return battery_status_.Charging();
}

double BatteryManager::chargingTime() {
  if (std::optional<double> v = camoucfg::GetDouble(
          camoucfg::ScopeFor(GetExecutionContext()),
          camoucfg::keys::kBatteryChargingTime)) {
    return *v;
  }
  return battery_status_.charging_time().InSecondsF();
}

double BatteryManager::dischargingTime() {
  if (std::optional<double> v = camoucfg::GetDouble(
          camoucfg::ScopeFor(GetExecutionContext()),
          camoucfg::keys::kBatteryDischargingTime)) {

  return battery_status_.discharging_time().InSecondsF();

double BatteryManager::level() {
  if (std::optional<double> v = camoucfg::GetDouble(
          camoucfg::ScopeFor(GetExecutionContext()),
          camoucfg::keys::kBatteryLevel)) {
    return *v;
