# SP4-geo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `CAMOU_CONFIG` synthesize the `navigator.geolocation` position at the Blink level, so a standalone (non-CDP) launch reports the configured latitude/longitude/accuracy — even with no geolocation backend — while respecting the permission model.

**Architecture:** Intercept `Geolocation::QueryNextPosition()` (`core/geolocation/geolocation.cc`): when `geolocation:latitude` + `geolocation:longitude` are set, synthesize a `device::mojom::blink::GeopositionResult` from config and deliver it via the existing `OnPositionUpdated` path (posted, not inline), bypassing the mojo backend. Reuses Chromium's own delivery/validation code; NOT a browser-process override and NOT a permission bypass.

**Tech Stack:** Chromium/Blink C++ (`core/geolocation`), `//components/camoucfg`, GN, Playwright verify over content_shell CDP.

## Global Constraints

- All spoofing at the C++/Blink level, NEVER injected JS. (project invariant)
- SP0 rule 5: no-op when the keys are absent. `geolocation:latitude` AND `geolocation:longitude` must BOTH be present to activate; otherwise the real mojo path runs unchanged.
- Config-key naming: colon namespace `geolocation:` (matching Camoufox). `geolocation:latitude`, `geolocation:longitude`, `geolocation:accuracy`.
- Keys triple-consistency: (1) `keys.h` constant, (2) `kAllKeys` array + `std::array<…, N>` size, (3) `declared` set in `keys_unittest.cc`. Count 67 → 70.
- `camoucfg::GetDouble(scope, key)` → `std::optional<double>`. `ScopeFor(nullptr)` returns GlobalScope.
- The synthesized `device::mojom::blink::Geoposition` must satisfy `ValidateGeoposition`: `latitude ∈ [-90,90]`, `longitude ∈ [-180,180]`, `accuracy ≥ 0`, `!timestamp.is_null()`. Set `accuracy = config.value_or(100.0)`, `timestamp = base::Time::Now()`. Leave altitude/heading/speed/altitude_accuracy at their mojom defaults (→ JS null).
- Deliver via `PostTask` (TaskType::kMiscPlatformAPI) of `OnPositionUpdated` with `WrapWeakPersistent(this)` — NOT a synchronous call (avoids the `updating_` re-entrancy: `QueryNextPosition` is called as `QueryNextPosition(); updating_ = true;`). It delivers once per arm, like the mojo one-shot — no watcher loop.
- Permission is respected: `QueryNextPosition` is only reached after the permission grant; do NOT auto-grant. A denied page still errors.
- No `BUILD.gn` change: `core/geolocation` compiles under the `core` target, which already deps `//components/camoucfg`. `geoposition.mojom-blink.h` is already included in `geolocation.cc`.
- Verify apparatus: geolocation is secure-context only — drive over the `127.0.0.1` echo_server origin (mirror `verify_sp4_media`). Launch with `CAMOU_CONFIG`, NO CDP override.
- Blink files live only in the checkout; edit via `pullfile`/`pushto`; extract to `patches/` in the final task. Confirm NON-ZERO build steps.

### Task 2: Blink — synthesize the position at QueryNextPosition

**Files:**
- Modify (checkout): `third_party/blink/renderer/core/geolocation/geolocation.cc`

**Interfaces:** Consumes `camoucfg::keys::kGeolocation*`.

- [ ] **Step 1: verify script `scripts/verify_sp4_geo.py`** (secure origin via echo_server, NO CDP):
- **G1 (config synthesizes):** config `{"geolocation:latitude":48.8566,"geolocation:longitude":2.3522,"geolocation:accuracy":25}` → `getCurrentPosition` succeeds with `lat==48.8566`, `lon==2.3522`, `acc==25`.
- **G2 (no-op absent):** config `{}` → `getCurrentPosition` errors with `code==3` (TIMEOUT), matching stock (rule 5).
- **G3 (accuracy default):** config lat+long only → succeeds with `acc==100`.
- **G4 (watchPosition):** config as G1 → `watchPosition` fires the success callback once with `lat==48.8566`.

```python
import json, os, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import lib_shell, echo_server

GET = r"""(async () => {
  return await new Promise((res) => {
    navigator.geolocation.getCurrentPosition(
      (p)=>res({ok:true, lat:p.coords.latitude, lon:p.coords.longitude, acc:p.coords.accuracy}),
      (e)=>res({ok:false, code:e.code}), {timeout:4000});
    setTimeout(()=>res({ok:false, timeout:true}), 5000);
  });
})()"""

WATCH = r"""(async () => {
  return await new Promise((res) => {
    const id = navigator.geolocation.watchPosition(
      (p)=>{ navigator.geolocation.clearWatch(id); res({ok:true, lat:p.coords.latitude}); },
      (e)=>res({ok:false, code:e.code}), {timeout:4000});
    setTimeout(()=>res({ok:false, timeout:true}), 5000);
  });
})()"""

def run(config, expr):
    url, _, stop = echo_server.start([])
    try:
        v, e = lib_shell.session(config, [expr], navigate_to=url)
        if e: raise e
        return v[0]
    finally:
        stop()

def cfg(d): return json.dumps(d)

def main():
    r = {}
    a = run(cfg({"geolocation:latitude":48.8566,"geolocation:longitude":2.3522,"geolocation:accuracy":25}), GET)
    r["G1"] = a.get("ok") and a["lat"]==48.8566 and a["lon"]==2.3522 and a["acc"]==25
    b = run(cfg({}), GET)
    r["G2"] = (not b.get("ok")) and b.get("code")==3
    c = run(cfg({"geolocation:latitude":10.0,"geolocation:longitude":20.0}), GET)
    r["G3"] = c.get("ok") and c["acc"]==100
    d = run(cfg({"geolocation:latitude":48.8566,"geolocation:longitude":2.3522,"geolocation:accuracy":25}), WATCH)
    r["G4"] = d.get("ok") and d["lat"]==48.8566
    EXPECTED=4
    for k in ("G1","G2","G3","G4"): print(f"{k}: {'PASS' if r[k] else 'FAIL'}")
    n=sum(r.values()); print(f"{n}/{EXPECTED} " + ("ALL_PASS" if n==EXPECTED else "FAIL"))
    sys.exit(0 if n==EXPECTED else 1)

if __name__=="__main__": main()
```
