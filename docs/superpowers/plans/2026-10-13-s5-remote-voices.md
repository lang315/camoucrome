**Goal:** A fork identity claiming Windows or macOS lists Chrome's 19 Google network voices after the local ones, as stock does. `speak()` on one of them has stock's event shape: no `boundary`, a delayed `start`, and stock's end/cut-off timing.

**Architecture:**

- **Blink.** The existing fake `speak()` path in `speech_synthesis.cc` (patch `voices-ii`) gets a branch on `voice.localService == false`, with constants measured on stock Chrome 154 on the Windows host in session 1.

**Tech Stack:**

## Global Constraints

- **No JavaScript injection.** Every change is data, the generator, or C++ in a patch.
- **No new config key.** The remote behaviour derives from each voice's `localService`, which `voices:list` already carries.
- **The local branch keeps its behaviour.** A voice with `localService: true` fires exactly what it fires on `main`: async `start` at delay 0, one `boundary` per word, `end` at `chars / (cps * rate) * (1 + jitter)`.

## Rulings made while planning

- **No macOS recapture.** On 2026-10-13, stock Chrome 155 on the owner's Mac listed 191 local voices. Their names and `lang` equal `voices.json`'s macOS list in order. Its 19 remote voices equal the Windows baseline's 19 in order, `name` and `lang`. So the committed macOS list is right, and the remote voices are one shared table.
  - The spec's "recapture in W0" is replaced by this check, recorded in the measurement doc §1.
  - `capture_voices.py` still gets a settle wait (Task 2), so a future capture cannot stop at a partial list.
- **Rate handling** is decided by Task 1's rate-2 cell: `divide` or `ignore`, by the rule in Task 1 Step 5.
- **Cut-off** exists only if Task 1 shows it (Task 1 Step 5 rule). Without one, `kRemoteCutoffMs = 0` and no cut-off code path fires.
- **Pause and cancel.** If the Google voice's `pause()` or `cancel()` shape differs from the local voice's on the host, stop and return to the owner (Task 1 Step 5). The plan implements only "same as local".
- **`start` and end use different jitter bits.** `start` uses the low 11 bits of the same FNV hash (`unit2`); end keeps the existing `unit` (`hash >> 11`). This avoids a page reading a start/end correlation.

def gpu_crash_count(ctx):
    """chrome://gpu "GPU process crash count", as S4's gpu_page read it; None if unread."""
    p = ctx.new_page()
    try:
        p.goto("chrome://gpu", wait_until="load", timeout=15000)
        for _ in range(20):
            txt = p.evaluate("(()=>{const o=[];const w=r=>{for(const e of r.querySelectorAll('*')){if(e.tagName==='LI'||e.tagName==='TR')o.push(e.textContent.replace(/\\s+/g,' ').trim());if(e.shadowRoot)w(e.shadowRoot)}};w(document);return o.join('\\n')})()")
            line = next((l for l in txt.splitlines() if l.startswith("GPU process crash count")), None)
            if line:
                return line.rpartition(":")[2].strip()
            time.sleep(0.25)
        return None
    finally:
        p.close()
