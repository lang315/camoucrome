# SP4-media Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Spoof `navigator.mediaDevices.enumerateDevices()` device counts at the Blink C++ level, controlled by config, invisible to page-side JS.

**Architecture:** Override the resolved device list in `MediaDevices::DevicesEnumerated` (the single JS-reachable resolution point) when `mediaDevices:enabled` is set: replace it with configured counts of empty-field devices per kind. Four config keys in `//components/camoucfg`, read via the established `blink_scope` accessor. Ports Camoufox's `media-device-spoofing.patch` behavior. The codec matrix (canPlayType/isTypeSupported/decodingInfo) is deliberately OUT of scope — a build-flag concern, not a Blink lie (see measurement §2).

**Tech Stack:** Chromium/Blink C++, `//components/camoucfg`, GN, Playwright verify over content_shell CDP.

## Global Constraints

- All spoofing at the C++/Blink level, NEVER injected JS. (project invariant)
- SP0 hook pattern: real value first, config override LAST, no-op when key absent (rule 5). An absent/false `mediaDevices:enabled` leaves the real device list untouched.
- Config-key naming: dot mirrors a JS property path exactly; colon names a synthetic namespace. `mediaDevices:` is synthetic (micros/webcams/speakers/enabled are not properties of the object) → colon. Matches Camoufox.
- Keys registry triple-consistency: every key in (1) a `keys.h` constant, (2) `kAllKeys` array + its `std::array<…,N>` size, (3) the `declared` set in `keys_unittest.cc`. Count 57 → 61.
- Defaults (Camoufox): micros=3, webcams=1, speakers=1.
- `camoucfg::GetBool` → `std::optional<bool>`; `camoucfg::GetUint32` → `std::optional<uint32_t>`. `ScopeFor(ExecutionContext*)` ignores its arg today (returns GlobalScope); pass `GetExecutionContext()` per the SP4a screen.cc precedent.
- `MediaDeviceType` order (`public/mojom/mediastream/media_devices.mojom`): `kMediaAudioInput`, `kMediaVideoInput`, `kMediaAudioOutput`, `kNumMediaDeviceTypes`.
- Verify apparatus: `enumerateDevices` is secure-context only — drive over the `127.0.0.1` `echo_server` origin (mirror `verify_sp4_fonts` F5). `about:blank` gives `navigator.mediaDevices === undefined`.
- Blink harness: edit checkout files via `runwsl`; camoucfg additions pushed via `pushcfg`; extract patch to `patches/` in the final task. Confirm NON-ZERO build steps after each change (stale `.o` → silent 0-step no-op).

- [ ] **Step 1: Write the failing verify script `scripts/verify_sp4_media.py`**

It drives content_shell over the `echo_server` secure origin. Criteria:
- **M1 (counts spoofed):** config `{mediaDevices:enabled:true, mediaDevices:micros:2, mediaDevices:webcams:3, mediaDevices:speakers:4}` → `byKind == {audioinput:2, videoinput:3, audiooutput:4}`, `count == 9`.
- **M2 (empty fields):** every device in the M1 run has `label==="" && deviceId==="" && groupId===""`.
- **M3 (defaults):** config `{mediaDevices:enabled:true}` with no count keys → `byKind == {audioinput:3, videoinput:1, audiooutput:1}`.
- **M4 (no-op when absent):** config `{}` (no mediaDevices keys) → list equals the stock baseline captured with `--capture-baseline` (SP0 rule 5). Also assert `isSecureContext===true` (apparatus sanity).

```python
import json, os, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import lib_shell, echo_server

PROBE = r"""(async () => {
  try {
    if (!navigator.mediaDevices) return {error: "mediaDevices undefined"};
    const d = await navigator.mediaDevices.enumerateDevices();
    const byKind = {};
    for (const x of d) byKind[x.kind] = (byKind[x.kind]||0)+1;
    return { count: d.length, byKind, secure: window.isSecureContext,
             fields: d.map(x => ({kind:x.kind, label:x.label, deviceId:x.deviceId, groupId:x.groupId})) };
  } catch(e) { return { error: String(e) }; }
})()"""

def run(config):
    url, _, stop = echo_server.start([])
    try:
        vals, err = lib_shell.session(config, [PROBE], navigate_to=url)
        if err: raise err
        return vals[0]
    finally:
        stop()

def cfg(d): return json.dumps(d)

BASELINE = os.path.join(os.path.dirname(os.path.abspath(__file__)), "sp4_media_baseline.json")

def main():
    if "--capture-baseline" in sys.argv:
        base = run(None)
        with open(BASELINE, "w") as f: json.dump(base, f)
        print("baseline captured:", json.dumps(base)); return
    results = {}
    m1 = run(cfg({"mediaDevices:enabled": True, "mediaDevices:micros": 2,
                  "mediaDevices:webcams": 3, "mediaDevices:speakers": 4}))
    results["M1"] = (m1.get("byKind") == {"audioinput":2,"videoinput":3,"audiooutput":4}
                     and m1.get("count") == 9)
    results["M2"] = all(x["label"]=="" and x["deviceId"]=="" and x["groupId"]==""
                        for x in m1.get("fields", [{"label":"x","deviceId":"x","groupId":"x"}]))
    m3 = run(cfg({"mediaDevices:enabled": True}))
    results["M3"] = m3.get("byKind") == {"audioinput":3,"videoinput":1,"audiooutput":1}
    m4 = run(cfg({}))
    with open(BASELINE) as f: base = json.load(f)
    results["M4"] = (m4.get("byKind") == base.get("byKind")
                     and m4.get("secure") is True)
    EXPECTED = 4
    for k in ("M1","M2","M3","M4"):
        print(f"{k}: {'PASS' if results[k] else 'FAIL'}")
    npass = sum(results.values())
    print(f"{npass}/{EXPECTED} " + ("ALL_PASS" if npass==EXPECTED else "FAIL"))
    sys.exit(0 if npass==EXPECTED else 1)

if __name__ == "__main__":
    main()
```

```cpp
  // SP4-media: override the enumerated device list with configured counts of
  // empty-field devices per kind. Absent/false gate => real list untouched.
  const camoucfg::ConfigScope& camou_scope =
      camoucfg::ScopeFor(GetExecutionContext());
  if (camoucfg::GetBool(camou_scope, camoucfg::keys::kMediaDevicesEnabled)
          .value_or(false)) {
    const uint32_t micros =
        camoucfg::GetUint32(camou_scope, camoucfg::keys::kMediaDevicesMicros)
            .value_or(3);
    const uint32_t webcams =
        camoucfg::GetUint32(camou_scope, camoucfg::keys::kMediaDevicesWebcams)
            .value_or(1);
    const uint32_t speakers =
        camoucfg::GetUint32(camou_scope, camoucfg::keys::kMediaDevicesSpeakers)
            .value_or(1);
    MediaDeviceInfoVector spoofed;
    for (uint32_t k = 0; k < micros; ++k) {
      spoofed.push_back(MakeGarbageCollected<InputDeviceInfo>(
          g_empty_string, g_empty_string, g_empty_string,
          mojom::blink::MediaDeviceType::kMediaAudioInput));
    }
    for (uint32_t k = 0; k < webcams; ++k) {
      spoofed.push_back(MakeGarbageCollected<InputDeviceInfo>(
          g_empty_string, g_empty_string, g_empty_string,
          mojom::blink::MediaDeviceType::kMediaVideoInput));
    }
    for (uint32_t k = 0; k < speakers; ++k) {
      spoofed.push_back(MakeGarbageCollected<MediaDeviceInfo>(
          g_empty_string, g_empty_string, g_empty_string,
          mojom::blink::MediaDeviceType::kMediaAudioOutput));
    }
    media_devices = std::move(spoofed);
  }
```
