# SP4-fonts (Layer 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the enumeration-visible font fingerprint at the Blink C++ level — disable the Local Font Access API, and make an unlisted specific `font-family` never resolve to a real host face (so `measureText` can't detect it) — driven by a `fonts` allowlist, with no injected JavaScript and no rendering breakage.

**Architecture:** A single `camoucfg::IsFontAllowed(scope, family)` allowlist predicate (rule 5: no `fonts` key ⇒ every host font visible) gates the two font selectors' `GetFontData` (window + worker) just before the host-font lookup, using the still-known `FamilyIsGeneric()` so generics and `@font-face` web fonts are never blocked. The `FontAccess` runtime feature is disabled so `window.queryLocalFonts` is gone.

**Tech Stack:** Chromium/Blink C++ (`third_party/blink/renderer`), `//components/camoucfg` (adds ONE new accessor `IsFontAllowed`), GN, Playwright 1.55.0 + content_shell CDP.

**Measurement basis:** `docs/superpowers/measurements/2026-08-31-sp4-fonts-surfaces.md` (HEAD `a727b57805`). Read it — it has the choke, the resolved gate design, the worker-parity reasoning, the #44 filter boundary, and the deferred layers.

## Global Constraints

- **C++/Blink only. No injected JavaScript.**
- **SP0 hook / rule 5:** `IsFontAllowed` returns `true` when the `fonts` key is absent — a no-op, every host font visible, stock behavior. The gate must never change rendering when unconfigured.
- **Generic + `@font-face` safety is mandatory.** The gate applies ONLY to `!FamilyIsGeneric()` specific families and sits AFTER the `@font-face` (`font_face_cache_`) check. Generics (`serif`/`sans-serif`/`monospace`/`system-ui`) and web fonts must always render. A "generics still render" verify criterion is required — blocking a generic is a rendering bug worse than a fingerprint.
- **Worker parity is mandatory.** The window selector (`CSSFontSelector`) and the worker/`OffscreenCanvas` selector (`OffscreenFontSelector`) both get the same gate; a dedicated-worker `measureText` parity criterion must prove it (a listed and an unlisted font measured in a worker match the window's answers).
- **One new accessor only:** `bool camoucfg::IsFontAllowed(const ConfigScope&, std::string_view family)`. No other new accessor. Case-insensitive membership.
- **This is a FILTER, not a font provider.** Visible set = (host fonts) ∩ (configured list). SP4-fonts does not guarantee the list is OS-plausible or the fonts are present to render — that is SP5b/packaging + the SP5a validator (the #44 boundary). Do not add coherence/OS-derivation here.
- **RED-first, no vacuous guards:** every gate needs a criterion that fails before it and passes after. If a gate's criterion cannot be made to go RED (the surface can't actually probe local fonts), DROP the gate and document why — do not ship an untestable no-op.
- **`-Werror -Wunreachable-code-aggressive`:** no stranded dead code.
- **Keys registry triple-consistency:** a new key goes in `keys.h` (constant + `kAllKeys` + array size) AND the `declared` set in `keys_unittest.cc`.

**Build/test harness:** source `buildpc.sh` (`runwsl`, `pushcfg`, `pullfile`, `pushto`, `contentshell`, `verify`, `unittests`). `additions/camoucfg/*` are copied into `<checkout>/components/camoucfg/`; Blink files are edited in the checkout and extracted to `patches/` in the final task. Confirm NON-ZERO build steps after each change. SSH-drop → report BLOCKED "ssh master down", no retry.

```cpp
namespace {
bool AsciiEqualsIgnoreCase(std::string_view a, std::string_view b) {
  if (a.size() != b.size())
    return false;
  for (size_t i = 0; i < a.size(); ++i) {
    if (base::ToLowerASCII(a[i]) != base::ToLowerASCII(b[i]))
      return false;
  }
  return true;
}
}  // namespace

bool IsFontAllowed(const ConfigScope& scope, std::string_view family) {
  if (!HasKey(scope, keys::kFonts))
    return true;  // rule 5: unconfigured => every host font visible.
  for (const std::string& allowed : GetStringList(scope, keys::kFonts)) {
    if (AsciiEqualsIgnoreCase(allowed, family))
      return true;
  }
  return false;
}
```
