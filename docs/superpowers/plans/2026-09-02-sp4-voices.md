# SP4-voices Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Inject a config-driven `speechSynthesis.getVoices()` list at the Blink level and fake `speak()` completion for those voices, so both the voice enumeration AND a speak()-probe are coherent and page-invisible.

**Architecture:** Add a typed `camoucfg::GetVoices` accessor (parses the `voices:list` JSON array into `VoiceConfig` structs, keeping `base::Value` out of the public API). In `blink::SpeechSynthesis`, build `voice_list_` from the config (getVoices + OnSetVoiceList), and intercept `StartSpeakingImmediately()` for an injected voice to synthesize start/end (or a deterministic error) instead of driving the (backend-less) mojo path. Ports Camoufox's voice + voice-completion spoofing.

**Tech Stack:** Chromium/Blink C++, `//components/camoucfg`, GN, Playwright verify over content_shell CDP.

## Global Constraints

- All spoofing at the C++/Blink level, NEVER injected JS. (project invariant)
- SP0 rule 5: no-op when the key is absent. Absent `voices:list` → stock voice list (empty on content_shell); absent fakeCompletion keys → their defaults apply only when a fake voice is actually spoken.
- Config-key naming: colon namespace. `voices:list`, `voices:fakeCompletion`, `voices:fakeCompletion:charsPerSecond` (bare `voices` is banned by `EveryKeyIsNamespaced`).
- Keys triple-consistency: (1) `keys.h` constant, (2) `kAllKeys` array + `std::array<…, N>` size, (3) `declared` set in `keys_unittest.cc`. Count 64 → 67.
- mojom shape (`third_party/blink/public/mojom/speech/speech_synthesis.mojom`): `SpeechSynthesisVoice { string voice_uri; string name; string lang; bool is_local_service; bool is_default; }`.
- Config entry keys mirror JS `SpeechSynthesisVoice` property names: `voiceURI`, `name`, `lang`, `localService` (default true), `default` (default false); missing `voiceURI` falls back to `name`.
- Fake-completion defaults: `voices:fakeCompletion` = true, `voices:fakeCompletion:charsPerSecond` = 12.5. When true, `speak()` on an injected voice fires `start` then a wall-clock-delayed `end` (delay = `text.length / (charsPerSecond * rate)` seconds); when false, a deterministic error.
- `camoucfg` public getters live in `mask_config.h`/`.cc`; internal helpers `GetXxxFrom(const base::DictValue&, key)` in `mask_config_internal.{h,cc}`; the public wrapper calls `internal::GetXxxFrom(internal::ParsedConfig(), key)`. `base::DictValue` = `base::Value::Dict`. `internal::WarnWrongType(key, expected)` logs a wrong-type warning.
- Blink files live only in the checkout; edit via `pullfile`/`pushto`; extract to `patches/` in the final task. Confirm NON-ZERO build steps after each change.

```cpp
std::vector<VoiceConfig> GetVoicesFrom(const base::DictValue& cfg,
                                       std::string_view key) {
  const base::Value* value = cfg.Find(key);
  if (!value) {
    return {};
  }
  if (!value->is_list()) {
    WarnWrongType(key, "a list");
    return {};
  }
  std::vector<VoiceConfig> out;
  for (const base::Value& entry : value->GetList()) {
    if (!entry.is_dict()) {
      WarnWrongType(key, "a list of voice objects");
      return {};
    }
    const base::Value::Dict& d = entry.GetDict();
    VoiceConfig v;
    if (const std::string* s = d.FindString("name")) {
      v.name = *s;
    }
    if (const std::string* s = d.FindString("lang")) {
      v.lang = *s;
    }
    if (const std::string* s = d.FindString("voiceURI")) {
      v.voice_uri = *s;
    } else {
      v.voice_uri = v.name;  // fall back to the display name
    }
    v.is_local_service = d.FindBool("localService").value_or(true);
    v.is_default = d.FindBool("default").value_or(false);
    out.push_back(std::move(v));
  }
  return out;
}
```
