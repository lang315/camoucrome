# Fonts: decision C answered — an open bundle, a fontconfig layer, and a `fonts:alias` key

Spec: `specs/2026-09-11-open-items-design.md` §1. The block on the
`system-ui`, CSS2-keyword and font-presence rows (d-gaps doc, sp4-fonts)
was a licensing call: `fonts:list` could hide host fonts but never make a
claimed family resolve. Decided and built on 2026-09-11.

## 1. Decision

**No proprietary font file is redistributed.** Segoe UI, Tahoma, Calibri,
San Francisco, Helvetica Neue and the rest of the Windows/macOS UI sets are
licensed to the OS. What ships instead: ten SIL OFL 1.1 sources
(`settings/fonts.json` `bundle`, sha256-pinned, `scripts/fetch_fonts.py`
into the git-ignored `fonts/`, 40 MB), and every family a real Windows or
macOS host exposes is mapped to one of them:

| claimed family | bundled target | relation |
|---|---|---|
| Segoe UI, Segoe UI Variable, DejaVu Sans, Ubuntu, Cantarell, every uncategorised Windows family | Selawik (Microsoft, OFL) | designed as a Segoe UI replacement; metric agreement unmeasured |
| Arial, Helvetica | Liberation Sans | metric-compatible |
| Times New Roman, Times | Liberation Serif | metric-compatible |
| Courier New, Courier, Consolas, Menlo, Monaco, … | Liberation Mono | Courier New metric-compatible; the rest presence only |
| Calibri / Cambria | Carlito / Caladea | metric-compatible |
| Georgia, Cambria Math, Constantia, Book Antiqua, … (serif class) | Liberation Serif | presence only |
| Yu Gothic, Meiryo, Microsoft YaHei, SimSun, Malgun Gothic, PingFang SC, Hiragino Sans, … (CJK class, 62 names) | Noto Sans CJK SC (16 MB) | glyph coverage; SC forms for JP/KR text |
| Symbol, Wingdings 1–3, Webdings, Marlett, Segoe MDL2/Fluent/Symbol/Historic/Print/Script, Apple Symbols, Apple Braille, … | Noto Sans Symbols 2 | presence only |
| Segoe UI Emoji, Apple Color Emoji | Noto Color Emoji (10 MB) | coverage |
| -apple-system, BlinkMacSystemFont, .AppleSystemUIFont, Helvetica Neue, SF Pro, every uncategorised macOS family | Inter Variable | presence only |

The family lists are **captured, not authored**: 118 families from the
box's Windows 10 host (`InstalledFontCollection` over ssh; two ASUS vendor
fonts excluded by name in `families.exclude`) and 180 from the Mac
(`system_profiler SPFontsDataType`; six user-installed developer fonts —
Hack Nerd Font ×3, JetBrains Mono ×2, Noto Emoji — excluded because their
`Location` sits under `~/Library/Fonts`, not `/System`: a list that carries
one developer font identifies the generator, every macOS identity claims the
whole list). The Windows list got the same location screen after the fact:
every entry of the `HKLM`/`HKCU` `...\CurrentVersion\Fonts` hives resolves
under `C:\Windows\Fonts` and `%LOCALAPPDATA%\Microsoft\Windows\Fonts` is
empty (0 non-system entries), so the two ASUS names were the whole
remainder. Provenance in the manifest.

## 2. Two layers, because one was measured insufficient

**fontconfig** (`settings/fontconfig/{windows,macos}.conf`, generated by
`scripts/gen_fontconfig.py` from the manifest, `--check` refuses drift):
`<dir prefix="relative">../../fonts</dir>` and nothing else — no system
directory, so DejaVu/Ubuntu/Cantarell can never resolve by name, which is
what closes the `system-ui`/CSS2-keyword rows — an xdg cache dir, and a
`binding="strong"` alias for every captured family and generic (140
Windows, 205 macOS). Both launchers and the Node client point
`FONTCONFIG_FILE` at the conf of the claimed OS (`ua:platform`, else the
preset's `os`) when a `fonts` dir sits beside the executable or is passed
(`launcher.json` `launch.fontconfig`; layout `<root>/fonts` +
`<root>/settings/fontconfig` in the repo, the archive and the box copy).

**Measured 2026-09-11: the conf alone does not rename a match for Chrome.**
With it in place `fc-match "Segoe UI"` gave Selawik, but the page rendered
"Segoe UI" at a third width and Consolas fell to the monospace fallback.
Skia's fontconfig path (`SkFontConfigInterfaceDirect::matchFamilyName`)
accepts a match only when the resolved family equals the requested one,
plus its own small metric-compatible table (Arial→Liberation Sans is why
`Arial` worked). So the alias moved into the fork:

**`fonts:alias`** (new key, `fonts-iii-alias.patch`): a dict requested
family → target family, consulted case-insensitively in
`FontCache::GetFontPlatformData` before any lookup, `system-ui` included.
The allowlist (`fonts:list`, `FontFallbackList`) has already judged the
requested name; pages observe widths, never the resolved name; a direct
request for a bundle name ("Selawik") is blocked by the allowlist, so the
bundle's own names never leak. The map is generated per OS into the
manifest's `alias_map` by `gen_fontconfig.py`; the generator emits
`fonts:list` (the captured list plus `-apple-system`/`BlinkMacSystemFont`/
`.AppleSystemUIFont` for a macOS claim, names real Chrome resolves without
a file) and `fonts:alias` together. `FontAliasTest` (unit) + gn check on
`//third_party/blink/renderer/platform:platform`.

Two guards found in review, both measured: **one hop.** The hook re-enters
`GetFontPlatformData` with the target, so a hand-written map with a cycle
(`{A:B, B:A}`) recursed until the renderer's stack ran out — a crash is a
fingerprint (CLAUDE.md's last line). A target that is itself a key of the
map is now not followed (the inner call finds no alias), so a chain or a
cycle degrades to the real lookup; F7 loads a page under exactly that map.
The generated maps have no such target (bundle names are never keys).
**`fonts-alias-requires-list`** (14th invariant, `requires-key`, repair):
`fonts:alias` without `fonts:list` would let a page request "Selawik" by
name and get it beside a "Segoe UI" of the same width — a set no Windows
host produces. Mutation in the unit test and the runner (7/7, 14).

## 3. Verify (`scripts/verify_fonts_bundle.py`, chrome through the probe)

Width test only: `document.fonts.check()` answers true for any never-loaded
family. A family resolves iff its width is the same under a monospace and a
serif fallback (an unresolvable one renders as the fallback and moves);
the probe string per class is one both Liberation fallbacks and the class's
target have glyphs for (Latin; the card suits for symbol/emoji fonts, which
have no Latin — a glyph absent from both fallbacks would be served by the
same system fallback either way and read as resolved).

| row | result |
|---|---|
| F1 RED, no bundle, no config: Segoe UI unresolvable, DejaVu Sans resolves | PASS |
| F2 Windows claim + bundle + list + alias: **116/116** families resolve, DejaVu Sans/Ubuntu/Cantarell hidden, `system-ui` == `Segoe UI` (Selawik through the alias) ≠ the blocked width, a direct "Selawik" blocked | PASS |
| F3 macOS claim: **180/180** resolve, host fonts hidden, `system-ui` == `-apple-system` (Inter) ≠ blocked, direct "Inter Variable" blocked | PASS |
| F4 `gen.py --os windows` emits a `fonts:list` ⊆ what F2 measured as resolving | PASS |
| F5 the extracted archive's chrome with `fonts/` beside it and no `--fonts-dir` (launcher finds it) | see packaging doc §3, fifth and sixth cuts |
| F6 worker parity (rule 3): a dedicated worker's `OffscreenCanvas` widths of Segoe UI / Consolas / Calibri == the main thread's under the F2 config | PASS, 416 / 540 / 373 on both |
| F7 cyclic `fonts:alias` `{A:B, B:A, "Segoe UI":A}`, non-strict, page requesting all three: chrome starts and the page reports | PASS (before the one-hop guard this was the renderer crash) |

Before the C++ alias (conf only): F2/F3 failed with `system-ui` at the
system fallback's width and every aliased family at the allowlist's
fallback width (373 px for the Latin probe string; Selawik itself measures
416 px when allowed, which is what `Segoe UI` reads after the alias) and every mono/symbol family unresolved — the measurement
that produced §2's second layer. `4 PASS 0 FAIL` after; `6 PASS 0 FAIL`
with F6/F7 (the probe now waits for `#o`, since a worker reports after
load). The width test cannot tell Carlito from the allowlist's fallback
font for the Latin probe string (both 373 px at 16 px); F2's resolves row
(mono vs serif fallback) is what proves Calibri resolves, F6 only compares
threads.

## 4. What remained, and where it went

The residual list this section used to hold was worked on 2026-09-11 in
`2026-09-11-fonts-metrics.md`: Selawik-vs-Segoe metrics measured (an
approximate clone, every character within 1.1 px at 100 px); Georgia got
Gelasio (0.984 within 0.5 px) and Tahoma Wine's Tahoma (1.6 px); Verdana,
Trebuchet MS and Consolas have no open clone and their distances are
numbers; CJK is five regional faces from one OTC; the emoji class is
measured by colour; `local()` by PostScript / full name works through a
second map, `fonts:aliasLocal`, read by the same hook (F-PSNAME closed). Still open, named there: hinting/AA is
unreachable without the real files; Windows/macOS hosts have no host build
to measure; Caladea's Google Fonts build misses Cambria's digit widths.
